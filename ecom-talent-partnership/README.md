# ECOM Talent Partnership — ברושור שותפות גיוס למעסיקים

ברושור תדמיתי בן 5 עמודי A4 לאורך, בעברית (RTL), לתוכנית שותפות הגיוס של מכללת איקום מול חברות הייטק וסטארטאפים. עיצוב עריכתי בהשראת דוחות שנתיים ומסמכי מותג — טיפוגרפיה גדולה, קווי שיער עדינים, גרפיקה מופשטת של קווים וצמתים.

## עריכה והפקה מחדש

1. עורכים את `ECOM-brochure.html` — הטקסטים בגוף הקובץ, צבעים/מידות במשתני ה־CSS שבראשו (`:root`).
2. מריצים:

```bash
node render.mjs
```

הסקריפט מפיק את שני קובצי ה־PDF ואת תצוגות העמודים אל `dist/` (אוטומטית, לפי מספר עמודי ה־`.page` בקובץ — אין צורך לעדכן את הסקריפט אם נוסף/הוסר עמוד).

לצפייה בדפדפן: פותחים את הקובץ ישירות (תצוגת בלִיד), או עם `?bleed=0` לתצוגת גודל סופי.

## להשלמה לפני שליחה

- **לוגו** — הלוגו הרשמי לא היה זמין בסביבת העבודה, ולכן בשער מוצב סימון־מקום טיפוגרפי (המשתמש יטמיע את הלוגו הרשמי בעצמו). מחליפים בבלוק המסומן `<!-- LOGO SLOT -->` בשער: מניחים את קובץ הלוגו ב־`assets/` ומחליפים את תוכן `.logo-slot` ב־`<img src="assets/logo.svg" style="height:100%">`. אין לשרטט את הלוגו מחדש.
- **פרטי קשר (עמוד 5)** — מולאו: רונית איש שלום, מנהלת מחלקת ההשמה, 051-5322892, jobs@ecomschool.co.il.
- **תמונות (עמוד 2)** — לפי הנחיה, העמוד אמור להשתמש בתמונות אמיתיות של סטודנטים/בוגרים/מרצים ולא בתמונות סטוק. בסביבת העבודה לא היו זמינות תמונות אמיתיות, ולא נוצרו תמונות מלאכותיות "כאילו אמיתיות" — זה היה מציג עדות מזויפת בדיוק בעמוד שתפקידו לבנות אמון. העמוד נבנה כרגע כולו מטיפוגרפיה ונתונים, עקבי עם שאר הברושור. אם תספקו תמונות אמיתיות, אפשר לשלב אותן בהמשך.
- **נתונים בעמוד 2** — הציונים/אחוזים/הסמכות (4.8 מתוך 5, 87% השמה, 2,500+ חברות, ISO 9001, רישיון השמה, שת"פ אוניברסיטת אריאל) הוזנו כפי שנמסרו. כדאי לוודא שהם מדויקים ועדכניים לפני שליחה חיצונית, בפרט ISO/רישיון/שת"פ אקדמי שהם טענות רגישות מבחינה משפטית.
