# ECOM Talent Partnership — ברושור שותפות גיוס למעסיקים

ברושור תדמיתי בן 4 עמודי A4 לאורך, בעברית (RTL), לתוכנית שותפות הגיוס של מכללת איקום מול חברות הייטק וסטארטאפים. עיצוב עריכתי בהשראת דוחות שנתיים ומסמכי מותג — טיפוגרפיה גדולה, קווי שיער עדינים, גרפיקה מופשטת של קווים וצמתים.

## מה בתיקייה

| קובץ | תיאור |
|---|---|
| `ECOM-brochure.html` | **קובץ המקור לעריכה** — כל התוכן, העיצוב והגרפיקה |
| `render.mjs` | סקריפט הפקה (Playwright + Chromium) |
| `dist/ECOM-Talent-Partnership.pdf` | PDF דיגיטלי — A4 מדויק, לשליחה לחברות |
| `dist/ECOM-Talent-Partnership-Print-Bleed.pdf` | PDF לדפוס — 216×303 מ"מ (בלִיד 3 מ"מ מכל צד) |
| `dist/previews/page-1..4.png` | תצוגה מקדימה של כל עמוד |
| `assets/fonts/` | Heebo (פונט משתנה, עברית + לטינית) |

## עריכה והפקה מחדש

1. עורכים את `ECOM-brochure.html` — הטקסטים בגוף הקובץ, צבעים/מידות במשתני ה־CSS שבראשו (`:root`).
2. מריצים:

```bash
node render.mjs
```

הסקריפט מפיק את שני קובצי ה־PDF ואת תצוגות העמודים אל `dist/`.

לצפייה בדפדפן: פותחים את הקובץ ישירות (תצוגת בלִיד), או עם `?bleed=0` לתצוגת גודל סופי.

## להשלמה לפני שליחה

- **לוגו** — הלוגו הרשמי לא היה זמין בסביבת העבודה, ולכן בשער מוצב סימון־מקום טיפוגרפי. מחליפים אותו בבלוק המסומן `<!-- LOGO SLOT -->` בשער: מניחים את קובץ הלוגו ב־`assets/` ומחליפים את תוכן `.logo-slot` ב־`<img src="assets/logo.svg" style="height:100%">`. אין לשרטט את הלוגו מחדש.
- **פרטי קשר (עמוד 4)** — שם מנהלת ההשמה, טלפון ודוא"ל מסומנים `[להשלים]`.
- **קוד QR (עמוד 4)** — כרגע סימון־מקום. מחליפים את ה־SVG שבתוך `.qr-box` בקוד QR אמיתי (קישור לתיאום שיחה).

## מפרט דפוס

- גודל עמוד: A4 לאורך (210×297 מ"מ), 4 עמודים נפרדים
- בלִיד: 3 מ"מ מכל צד (בקובץ ה־Print)
- שוליים בטוחים: 16 מ"מ מקו החיתוך
- פונט: Heebo בלבד, מוטמע בקובץ
- צבעי מותג: `#8C52FF` (סגול איקום), `#0D0D18` (כהה), `#F5F4F8` (רקע בהיר), `#767482` (אפור), `#496DFF` (כחול משני — צד החברה)
