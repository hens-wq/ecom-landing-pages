# ECOM Talent Partnership — חומרי שותפות גיוס למעסיקים

שני חומרים תדמיתיים בעברית (RTL) לתוכנית שותפות הגיוס של מכללת Ecom מול חברות הייטק וסטארטאפים, באותה שפה עיצובית — רקע כהה, טיפוגרפיה גדולה, גרפיקת קווים/צמתים ואייקונים מינימליים, סגול · כחול · תכלת:

1. **ברושור** (`ECOM-brochure.html`) — 5 עמודי A4 לאורך, להדפסה או שליחה כ־PDF.
2. **מצגת** (`ECOM-presentation.html`) — 7 שקפים ביחס 16:9, לשיחת זום/מצגת עסקית. נבנתה מחדש כמצגת עצמאית עם פריסה, טיפוגרפיה ומבנה תוכן משלה — לא גרסה מסובבת או מוקטנת של הברושור. מיועדת למצגת בעל פה: משפטי מפתח וטיפוגרפיה גדולה בלבד על השקפים, ללא פסקאות הסבר — התוכן המלא מגיע מהדובר/ת.

## עריכה והפקה מחדש

**ברושור** — עורכים את `ECOM-brochure.html` (טקסטים בגוף הקובץ, צבעים/מידות במשתני ה־CSS שבראשו) ומריצים:

```bash
node render.mjs
```

הסקריפט מפיק את שני קובצי ה־PDF ואת תצוגות העמודים אל `dist/` (אוטומטית, לפי מספר עמודי ה־`.page` בקובץ). לצפייה בדפדפן: פותחים את הקובץ ישירות (תצוגת בלִיד), או עם `?bleed=0` לתצוגת גודל סופי.

**מצגת** — עורכים את `ECOM-presentation.html` באותו אופן ומריצים:

```bash
node render-presentation.mjs
```

הסקריפט מפיק את קובץ ה־PDF ואת תצוגות השקפים אל `dist/` (אוטומטית, לפי מספר השקפים בקובץ). המצגת ללא בלִיד — פורמט מסך/דיגיטלי בלבד.

## להשלמה לפני שליחה

- **לוגו** — לוגו ECOM School האמיתי (מקובץ שסופק) מופיע כעת בפינה השמאלית העליונה בכל אחד מ־5 העמודים, בגודל אחיד ופרופורציונלי. הרקע האפור הוסר (שקיפות מלאה), והעיצוב עצמו — המשולשים, השם והטאגליין — לא שונה.
- **פרטי קשר (עמוד 5)** — מולאו: רונית איש שלום, מנהלת מחלקת ההשמה, 051-5322892, jobs@ecomschool.co.il — בכרטיס אחד מאוחד, טלפון/מייל משמאל לימין.
- **תמונות (עמוד 2)** — לא נעשה שימוש בתמונות אמיתיות או מלאכותיות של אנשים. לא היו זמינות תמונות אמיתיות של סטודנטים/בוגרים/מרצים בסביבת העבודה, ובכוונה לא נוצרו תמונות "כאילו אמיתיות" — זה היה עדות מזויפת בדיוק בעמוד שתפקידו לבנות אמון. העמוד בנוי מטיפוגרפיה, כרטיס ביקורות Google ונתונים. אם תספקו תמונות אמיתיות, אפשר לשלב אותן בהמשך.
- **נתונים שמופיעים במסמך** — דירוג Google (4.8/5, 300+ ביקורות, עמוד 2) ושיתוף הפעולה עם יחידת לימודי החוץ של אוניברסיטת אריאל (עמוד 2) הוזנו כפי שנמסרו. כדאי לוודא שהם מדויקים ועדכניים לפני שליחה חיצונית — בפרט שיתוף הפעולה האקדמי, שהיא טענה רגישה מבחינה משפטית. (האחוזים/ISO/מספר החברות שהוזנו בסבב קודם הוסרו מהמסמך בהנחייתכם המפורשת.)
