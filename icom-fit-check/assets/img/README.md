# נכסי Nano Banana

כל 9 הנכסים שנוצרו ב־**Nano Banana 2** נמצאים בתיקייה הזו ומשולבים בדף:

| קובץ | היכן מופיע |
|------|------------|
| `hero-character.jpg` | פורטל ה־Hero במסך הפתיחה + רקע מטושטש במסך הקורסים |
| `bg-ambient.jpg` | רקע אווירה גלובלי מאחורי כל המסכים |
| `track-cyber.jpg` | אייקון קורס סייבר ואבטחת מידע |
| `track-ai.jpg` | אייקון קורס AI למפתחים |
| `track-qa.jpg` | אייקון קורס QA בדיקות תוכנה |
| `track-fullstack.jpg` | אייקון קורס מפתח Full Stack |
| `track-marketing.jpg` | אייקון קורס שיווק דיגיטלי |
| `track-uxui.jpg` | אייקון קורס UX/UI עיצוב גרפי |
| `track-devops.jpg` | אייקון קורס DevOps |

## החלפת נכס

שמרו קובץ חדש באותו שם — או עדכנו את הנתיב ב־`js/config.js`
(שדות `art`, `hero.art`, `AMBIENT_BG`).

## כיבוי התמונות

ב־`js/config.js`: `ASSETS_READY: false` יחזיר את אייקוני ה־SVG,
ו־`hero.ART_READY: false` יחזיר את הקומפוזיציה ההולוגרפית (טרמינל + תלת־ממד) בפורטל.

עותקי מקור שמורים גם בספריית Pixelcut:
https://www.pixelcut.ai/share/54d931f8-3e0c-44a1-af46-1429688d692b
