# נכסי Nano Banana — הוראות התקנה

8 נכסים גרפיים נוצרו עבור הדף באמצעות **Nano Banana 2** ושמורים בספריית Pixelcut של החשבון.

> סביבת הפיתוח המרוחקת חסמה הורדה ישירה של קבצים לכאן (מדיניות רשת),
> לכן ההורדה מתבצעת ידנית בקליק אחד מקישור השיתוף:

**קישור להורדת כל הנכסים:**
https://www.pixelcut.ai/share/db98c865-6443-48e0-8e68-9dbd3d20d355

## שלבי התקנה

1. פתחו את קישור השיתוף והורידו את 8 התמונות.
2. שמרו אותן **בתיקייה הזו** (`assets/img/`) בשמות הבאים (לפי סדר היצירה בקישור):

| # | קובץ | תיאור |
|---|------|-------|
| 1 | `track-cyber.webp`     | מגן הולוגרפי נסרק — סייבר התקפי |
| 2 | `track-ai.webp`        | כדור רשת נוירונים — AI |
| 3 | `track-qa.webp`        | זכוכית מגדלת על מעגל — QA ואוטומציה |
| 4 | `track-fullstack.webp` | שכבות זכוכית מחוברות — Full Stack |
| 5 | `track-marketing.webp` | גרף עולה זוהר — שיווק דיגיטלי ודאטה |
| 6 | `track-uxui.webp`      | פאנלים של ממשק מרחפים — UX/UI |
| 7 | `track-devops.webp`    | לולאת אינסוף של אור — DevOps |
| 8 | `bg-ambient.webp`      | רקע אווירה כהה (אופציונלי) |

   *הקבצים יורדים כ־PNG — מומלץ להמיר ל־WebP ברוחב ‎512px (למשל ב־squoosh.app)
   לטעינה מהירה במובייל. אפשר גם להשאיר PNG ולעדכן את הסיומות ב־`js/config.js`.*

3. פתחו את `js/config.js` ושנו:

```js
ASSETS_READY: true,
```

זהו. הכרטיסים יציגו את התמונות במקום אייקוני ה־SVG המובנים.
כל עוד הדגל כבוי — הדף מציג אייקוני SVG בגרדיאנט המותג, חדים ומהירים.
