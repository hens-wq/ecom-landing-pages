# נכסי Nano Banana — הוראות התקנה

> **הדרך המהירה ביותר:** אם התמונות כבר אצלכם במחשב — העלו אותן ישירות לתיקייה הזו
> דרך GitHub (בדף הענף: Add file ← Upload files), בשמות שבטבלה למטה,
> ובקשו מ־Claude "למשוך את התמונות ולהדליק את הדגלים" — והוא ישלים את השילוב.

9 נכסים גרפיים נוצרו עבור הדף באמצעות **Nano Banana 2** ושמורים בספריית Pixelcut של החשבון.

> סביבת הפיתוח המרוחקת חסמה הורדה ישירה של קבצים לכאן (מדיניות רשת),
> לכן ההורדה מתבצעת ידנית בקליק אחד מקישור השיתוף:

**קישור להורדת כל הנכסים:**
https://www.pixelcut.ai/share/54d931f8-3e0c-44a1-af46-1429688d692b

## שלבי התקנה

1. פתחו את קישור השיתוף והורידו את התמונות.
2. שמרו אותן **בתיקייה הזו** (`assets/img/`) בשמות הבאים:

| קובץ | תיאור |
|------|-------|
| `hero-character.webp` | **דמות ה־Hero** — סטודנט הייטק בתאורת ניאון (התמונה האנכית) |
| `track-cyber.webp`     | מגן הולוגרפי נסרק — סייבר התקפי |
| `track-ai.webp`        | כדור רשת נוירונים — AI |
| `track-qa.webp`        | זכוכית מגדלת על מעגל — QA ואוטומציה |
| `track-fullstack.webp` | שכבות זכוכית מחוברות — Full Stack |
| `track-marketing.webp` | גרף עולה זוהר — שיווק דיגיטלי ודאטה |
| `track-uxui.webp`      | פאנלים של ממשק מרחפים — UX/UI |
| `track-devops.webp`    | לולאת אינסוף של אור — DevOps |
| `bg-ambient.webp`      | רקע אווירה כהה (אופציונלי) |

   *הקבצים יורדים כ־PNG — מומלץ להמיר ל־WebP (למשל ב־squoosh.app): הדמות ברוחב ‎960px,
   האייקונים ברוחב ‎512px. אפשר גם להשאיר PNG ולעדכן את הסיומות ב־`js/config.js`.*

3. פתחו את `js/config.js` והדליקו את הדגלים:

```js
ASSETS_READY: true,        // אייקוני המסלולים
hero: {
  ART_READY: true,         // דמות ה־Hero
  ...
}
```

## מה קורה בלי הקבצים?

הדף עובד מצוין גם בלעדיהם:
- במקום הדמות מוצגת צללית עיצובית עם תאורת ניאון בצבעי המותג
- במקום האייקונים מוצגים אייקוני SVG בגרדיאנט המותג

כשהדגלים נדלקים, הדמות נכנסת לפורטל במסך הפתיחה, ומופיעה גם
כרקע אווירה מטושטש ועדין במסך בחירת המסלולים.
