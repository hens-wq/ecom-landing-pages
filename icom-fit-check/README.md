# בדיקת התאמה אינטראקטיבית · מכללת איקום

דף נחיתה חווייתי המשתלב במשפך הלידים: הלקוח מגיע מוואטסאפ, בוחר תחום לימודים,
משחק משחק חשיבה קצר המותאם לתחום, מקבל ציון התאמה (90–100) וחוזר לוואטסאפ להמשך התהליך.

**סטאק:** HTML + CSS + JavaScript ונילה. בלי Build, בלי תלויות, בלי Frameworks —
פותחים ועורכים כל קובץ ישירות.

---

## הפעלה

אין צורך בהתקנה. שתי אפשרויות:

```bash
# אפשרות 1 — פתיחה ישירה
פתחו את icom-fit-check/index.html בדפדפן (דאבל־קליק)

# אפשרות 2 — שרת מקומי (מומלץ לבדיקת מובייל ברשת המקומית)
cd icom-fit-check
python3 -m http.server 8080
# ואז: http://localhost:8080
```

הדף דורש אינטרנט רק לטעינת פונט Heebo מ־Google Fonts (יש Fallback לפונט מערכת).

## החלפת קישור הוואטסאפ

`js/config.js`, שורות ראשונות:

```js
WHATSAPP_RETURN_URL: 'https://wa.me/972500000000?text=...',
```

החליפו בקישור האמיתי (למשל קישור חזרה לבוט). הכפתור במסך התוצאה מתעדכן אוטומטית.

## חיבור Webhook (Make / CRM)

1. `js/config.js`:

```js
WEBHOOK_URL: 'https://hook.eu1.make.com/XXXXXXXX',
```

2. זהו — הפונקציה `sendAssessmentResult()` (ב־`js/app.js`) כבר שולחת `POST` עם JSON
   ברגע הצגת התוצאה. כשהכתובת ריקה היא מדפיסה את ה־Payload ל־Console.

מבנה ה־Payload:

```json
{
  "source": "icom-fit-check",
  "track": "ai",
  "trackName": "AI",
  "game": "השלמת הדפוס",
  "score": 96,
  "correctCount": 2,
  "totalAttempts": 3,
  "actions": ["pattern_square", "pattern_triangle", "series_5"],
  "reactionTimesMs": [1840, 1210],
  "avgReactionMs": 1525,
  "startedAt": "…", "finishedAt": "…", "completedAt": "…",
  "userAgent": "…"
}
```

אותם נתונים נשמרים גם ב־Local Storage (`icomFitCheck:lastResult` + היסטוריה).

## מדידה ואנליטיקה

כל האירועים נדחפים ל־`window.dataLayer` (תואם Google Tag Manager):

| אירוע | מתי |
|-------|-----|
| `fit_page_view` | כניסה לדף |
| `fit_start_click` | לחיצה על "מתחילים את הבדיקה" |
| `fit_track_selected` | בחירת תחום (+ `track`) |
| `fit_game_start` | תחילת משחק |
| `fit_game_complete` | סיום משחק (+ דיוק, ניסיונות) |
| `fit_result_shown` | הצגת תוצאה (+ `score`) |
| `fit_whatsapp_click` | לחיצה לחזרה לוואטסאפ |

חיבור GTM: הדביקו את קוד ה־Container ב־`index.html` (יש הערה מוכנה ב־`<head>`).
חיבור Meta Pixel: דרך GTM, או בהוספת `fbq()` בנקודה המסומנת ב־`js/analytics.js`.

חדים, מהירים, ללא תלות ברשת. אחרי ההורדה הדמות מופיעה גם כרקע אווירה מטושטש במסך המסלולים.

## מה כלול

- **7 משחקים ייעודיים** — סריקת פריצה (סייבר), השלמת דפוס (AI), ציד באגים (QA),
  חיבור Front↔Back‏ (Full Stack), קריאת נתונים (שיווק), השוואת גרסאות (UX/UI),
  תיקון Pipeline‏ (DevOps)
- ספירה לאחור, מד התקדמות, פידבק מיידי, אנימציות הצלחה, רטט במובייל
- צלילים עדינים (WebAudio) — כבויים כברירת מחדל, מופעלים בכפתור שבפינה
- מסך "ניתוח תוצאה" (~2.5 שניות) לפני חשיפת הציון
- ציון תמיד 90–100 (מבוסס לכאורה על מהירות/דיוק; 100 נדיר לשמירה על אמינות)
- תמיכת מקלדת בדסקטופ: מקשים 1–3 לבחירה, רווח לפעולה
- Mobile First‏, RTL מלא, ללא גלילה אופקית, עמיד במסכים נמוכים
- `prefers-reduced-motion` — כיבוי אנימציות דקורטיביות אוטומטי
- מקום שמור ללוגו ב־Header‏ (`index.html`, מסומן בהערה `LOGO`)
