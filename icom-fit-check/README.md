# בדיקת התאמה אינטראקטיבית · מכללת איקום

דף נחיתה חווייתי המשתלב במשפך הלידים: הלקוח בוחר קורס, עובר אתגר חשיבה קצר
המותאם לקורס, ומקבל ציון התאמה (90–100).

**סטאק:** HTML + CSS + JavaScript ונילה. בלי Build, בלי תלויות — פותחים ועורכים כל קובץ ישירות.

---

## הפעלה

```bash
# אפשרות 1 — פתיחה ישירה
פתחו את icom-fit-check/index.html בדפדפן (דאבל־קליק)

# אפשרות 2 — שרת מקומי
cd icom-fit-check
python3 -m http.server 8080
# ואז: http://localhost:8080
```

## מבנה החוויה

1. **פתיחה** — Hero הולוגרפי (טרמינל חי + אובייקט תלת־ממד), טקסט שיווקי וכפתור התחלה.
   כשמורידים את תמונת הדמות (ראו `assets/img/README.md`) היא נכנסת לפורטל אוטומטית.
2. **בחירת קורס** — 7 כרטיסים עם שם הקורס ושכר התחלתי:
   סייבר ואבטחת מידע (16,000), AI למפתחים (14,500), QA בדיקות תוכנה (11,000),
   מפתח Full Stack (15,000), שיווק דיגיטלי (12,000), UX/UI עיצוב גרפי (11,000), DevOps (16,000).
3. **אתגר** — מסך הוראות → ספירה לאחור → 2–3 שאלות מותאמות לקורס.
   - ניסיון אחד לכל שאלה: טעות חושפת את התשובה הנכונה וממשיכים הלאה.
   - טיימר של 20 שניות. נגמר הזמן? מסך "אופס, הזמן נגמר" עם כפתור ניסיון נוסף — בלי ציון.
4. **ניתוח + תוצאה** — אנימציית ניתוח (~2.5 שניות), ציון 90–100, קונפטי,
   וכפתור "לבדוק קורס נוסף".

## מנגנון הציון

הציון תמיד בטווח 90–100 (מוגדר ב־`config.js`) ומחושב לכאורה לפי דיוק ומהירות.
100 מופיע רק בביצוע מושלם ובהסתברות נמוכה. מי שלא סיים בזמן לא מקבל ציון —
אלא הזמנה לניסיון נוסף.

## חיבור Webhook (Make / CRM)

ב־`js/config.js`:

```js
WEBHOOK_URL: 'https://hook.eu1.make.com/XXXXXXXX',
```

הפונקציה `sendAssessmentResult()` (ב־`js/app.js`) שולחת POST עם JSON מלא
(קורס, ציון, תשובות, זמני תגובה, ניסיונות חוזרים) ברגע הצגת התוצאה.
כשהכתובת ריקה — הנתונים מודפסים ל־Console ונשמרים ב־Local Storage.

## החזרת כפתור הוואטסאפ

הכפתור הוסר ממסך התוצאה לפי בקשה. אם תרצו להחזירו: הקישור עדיין שמור
ב־`config.js` תחת `WHATSAPP_RETURN_URL`, וגרסת הכפתור המלאה נמצאת
בהיסטוריית הגיט (קומיט `69b4845`).

## מדידה ואנליטיקה

אירועים ב־`window.dataLayer` (תואם GTM):
`fit_page_view`, `fit_start_click`, `fit_track_selected`, `fit_game_start`,
`fit_game_timeout`, `fit_game_retry`, `fit_game_complete`, `fit_result_shown`.
חיבור GTM: הדביקו את קוד ה־Container ב־`index.html` (הערה מוכנה ב־`<head>`).
