# שכבת האינטגרציה הבטוחה (Safe Integration Layer)

תיקייה זו מכילה **תוכניות טכניות (specs)**, לא קוד פעיל שמתחבר לשום מערכת. שום קרדנציאל לא התבקש, שום חיבור לא בוצע. מסמך היסוד: `../SAFE_INTEGRATION_PLAN.md`.

## מסמכים בתיקייה זו

| קובץ | נושא |
|---|---|
| `01_wordpress_draft_creation_plan.md` | איך תיווצר טיוטת פוסט בוורדפרס (POST בלבד, `status=draft` קשיח) |
| `02_search_console_readonly_import_plan.md` | איך ייובאו נתוני Search Console בקריאה-בלבד |
| `03_analytics_readonly_import_plan.md` | איך ייובאו נתוני Google Analytics (GA4) בקריאה-בלבד |
| `04_approval_gate_plan.md` | המנגנון הטכני שאוכף שאף טיוטה לא נוצרת ללא אישור אנושי רשום |
| `05_credentials_checklist.md` | רשימה מדויקת של כל קרדנציאל נדרש וההיקף (scope) המדויק שלו – **טרם התבקש, טרם סופק** |

## סדר הטמעה מומלץ (רק לאחר אישור המשתמש, שלב אחר שלב)

```
04 (שער אישור) → 02+03 (ייבוא קריאה-בלבד, סיכון נמוך) → 01 (יצירת טיוטה, סיכון גבוה יותר - אחרון בכוונה)
```

שער האישור (04) מוטמע ונבדק **לפני** שמוטמעת כל יכולת כתיבה (01), כך שהוא קיים ונבדק במלואו לפני שיש בכלל מה "לשער".
