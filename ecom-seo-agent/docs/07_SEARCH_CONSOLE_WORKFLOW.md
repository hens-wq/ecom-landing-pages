# 07 – תהליך עבודה מול Search Console / Analytics

## מצב חיבור נוכחי

**אין כרגע חיבור API** ל-Google Search Console, Google Analytics, או Google Sheets. העבודה מתבססת על **ייצוא ידני של קבצי CSV** על ידי המשתמש, שמונחים בתיקיות הקלט המתאימות. חיבור API עתידי אפשרי, אך רק לאחר בקשה מפורשת של המשתמש ואספקת הרשאות.

## איפה מניחים קבצים

| מקור | תיקייה |
|---|---|
| ייצוא Google Search Console (Performance) | `data/input/search_console_exports/` |
| ייצוא Google Analytics (GA4) | `data/input/analytics_exports/` |
| הערות/ייצוא מהאתר (HTML, טקסט, screenshots) | `data/input/website_exports/` |
| הערות מחקר מתחרים | `data/input/competitor_notes/` |

## איך מייצאים מ-Search Console (הנחיה למשתמש)

1. Search Console → Performance → בחירת טווח תאריכים (מומלץ 3 חודשים אחרונים + השוואה לתקופה קודמת).
2. לשונית "Queries" → Export → CSV, ולשונית "Pages" → Export → CSV.
3. שמירת הקבצים בשם ברור, למשל: `gsc_queries_2026-04_2026-06.csv`, `gsc_pages_2026-04_2026-06.csv`.
4. להעביר לתיקיית `data/input/search_console_exports/`.

## דוחות שהסוכן מייצר מקבצי GSC

1. **שאילתות עם חשיפה גבוהה ו-CTR נמוך** – הזדמנות לשיפור כותרת/meta.
2. **עמודים קרובים לעמוד 1** (Position 11-20) – מועמדים לחיזוק מהיר (quick wins).
3. **עמודים שמאבדים תנועה** – השוואת שתי תקופות (נדרשים שני קבצי ייצוא).
4. **עמודים עם חשיפה אך כותרת/meta חלשים** – שילוב בין נתוני חשיפה לביקורת ה-on-page.
5. **מילות מפתח ללא עמוד יעד ייעודי** – שאילתות עם ביצועים אך ללא עמוד ברור מהמלאי (Workflow 2).
6. **התראות קניבליזציה** – כמה URLs מדורגים לאותה שאילתה.
7. **הזדמנויות קישור פנימי** – עמודים חזקים שיכולים "להעביר" כוח לעמודי קורס בעדיפות.
8. **דוח התקדמות SEO חודשי** – מגמות כוללות (קליקים, חשיפות, CTR ממוצע, דירוג ממוצע) לאורך זמן.
