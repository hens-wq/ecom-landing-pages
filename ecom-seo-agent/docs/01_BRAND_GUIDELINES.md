# 01 – הנחיות מותג

## זהות בסיסית

- **שם המותג:** מכללת איקום / Ecom School
- **אתר:** https://www.ecomschool.co.il/
- **בלוג:** https://www.ecomschool.co.il/blog/
- **פלטפורמה:** WordPress עם Elementor

## תיאור המכללה (לשימוש עקבי בתכנים)

מכללת איקום היא מכללה ללימודי הייטק אונליין. מסלולים מרכזיים: סייבר, AI, שיווק דיגיטלי ודאטה, Full Stack, QA, DevOps, UX/UI. הלימודים מתקיימים אונליין לייב וכוללים הקלטות. קיימת מכינה / קורסי הכנה בהתאם למסלול.

## קהל יעד

- צעירים בתחילת דרכם המקצועית
- חיילים משוחררים
- מחליפי קריירה (הסבה מקצועית)
- אנשים ששוקלים כניסה להייטק ללא רקע טכני קודם

## טון דיבור (Tone of Voice)

| כן | לא |
|---|---|
| מקצועי, עברית ישראלית טבעית | שיווקי-זול, בומבסטי |
| ברור ותכליתי | מבוסס פחד ("תפספסו את ההזדמנות!") |
| בונה אמון, מציג עובדות | הבטחות תוצאה |
| מעשי וממוקד | ניסוח מעורפל שמרמז הבטחה |
| נחרץ אך אמין (strong but credible) | "spam"-י, גדוש מילות מפתח |

## עובדות מותג – לשימוש **זהיר בלבד**

עובדות אלה ניתנות לשימוש בתוכן **רק** כאשר הן רלוונטיות להקשר, מנוסחות באחריות, ומאומתות. עובדות המסומנות "טעון אישור" **אסור** שיופיעו בתוכן שמיועד לפרסום עד לאישור מפורש של המשתמש (hens@ecomschool.co.il או מי מטעמו).

| עובדה | סטטוס | הערת שימוש |
|---|---|---|
| מסלולי לימוד: סייבר, AI, שיווק דיגיטלי ודאטה, Full Stack, QA, DevOps, UX/UI | מאושר לשימוש כללי | עובדה מבנית, לא טענת תוצאה |
| קיים מערך ליווי והשמה | מאושר לשימוש **בניסוח זהיר** | ראו ניסוחים מותרים ב-`02_SEO_RULES_AND_COMPLIANCE.md` – לעולם לא "הבטחת השמה" |
| לימודים אונליין לייב + הקלטות | מאושר לשימוש כללי | עובדה מבנית |
| קיימת מכינה/קורסי הכנה לפי מסלול | מאושר לשימוש כללי | עובדה מבנית |
| קהילת Ecom+ | מאושר לשימוש כללי | ניתן להציג כערך מוסף לבוגרים/סטודנטים |
| מרצים מהתעשייה | מאושר לשימוש כללי | יש לוודא דיוק מול האתר בפועל בכל עמוד ספציפי |
| סיפורי בוגרים | מאושר לשימוש **רק אם קיימים בפועל ומאומתים** | אין להמציא ציטוטים או שמות |
| שיתוף פעולה עם היחידה ללימודי חוץ והמשך של אוניברסיטת אריאל | **טעון אישור** | להשתמש רק אם הטענה מאושרת ומופיעה כבר באתר בפועל |
| ISO 9001 | **טעון אישור** | דורש אימות תיעודי לפני פרסום |
| ספק מאושר משרד הביטחון | **טעון אישור** | טענה רגישה – דורשת אימות תיעודי ואולי בדיקה משפטית |
| רישיון השמה | **טעון אישור** | דורש אימות תיעודי |
| 87% השמה / שכר פתיחה ממוצע | **טעון אישור מפורש מהמשתמש בכל שימוש** | לעולם לא כהבטחה אישית; רק כנתון סטטיסטי היסטורי, עם ניסוח "נתונים על בסיס מידע פנימי / נתוני עבר בלבד" |

**כלל עבודה:** בכל פעם שתוכן מתבסס על שורה שמסומנת "טעון אישור", הסוכן מסמן את הפריט (Task) בסטטוס **"Needs legal/compliance check"** ולא מתקדם לשלב טיוטת וורדפרס עד קבלת אישור מפורש (ראו `09_APPROVAL_PROCESS.md`).
