# ביקורת SEO – דף הבית

## מטא

- **עמוד:** https://www.ecomschool.co.il/
- **תאריך:** 2026-07-02
- **מקור הנתונים:** אין גישה חיה בסבב זה (ראו `00_MVP2_STATUS_AND_NEXT_STEPS.md`) – ביקורת מבנית/אסטרטגית בלבד
- **סטטוס:** Draft

## 1. תפקיד דף הבית באסטרטגיה

דף הבית הוא נקודת הכניסה הממותגת המרכזית ונמצא במרכז אסטרטגיית ה-Brand SERP (`docs/08_BRAND_SERP_STRATEGY.md`) עבור החיפוש "מכללת איקום". תפקידו הכפול: (א) לדרג עבור חיפושים ממותגים, (ב) להעביר "כוח SEO" פנימי לארבעת דפי הקורס בעדיפות.

## 2. רשימת בדיקה (למילוי מול תוכן אמיתי)

| בדיקה | סטטוס |
|---|---|
| Title Tag כולל "מכללת איקום" + הצעת ערך ברורה | ממתין לנתונים |
| Meta Description מושך קליק, ללא הבטחת תוצאה | ממתין לנתונים |
| H1 קיים, ממותג, לא כפול | ממתין לנתונים |
| קישורים בולטים (לא רק בתפריט נפתח) לארבעת דפי הקורס בעדיפות | ממתין לנתונים |
| קישורי פוטר לעמודי אמון (FAQ/חוות דעת/אודות) | ממתין לנתונים – רלוונטי גם לעמודים שטרם נוצרו |
| Organization / EducationalOrganization schema | ממתין לנתונים |
| מהירות טעינה וידידותיות מובייל (בסיסי) | ממתין לנתונים – מחוץ לתחום MVP הנוכחי |

## 3. המלצות עדיפות (לא תלויות בבדיקת התוכן הקיים)

1. לוודא ש-H1 ממותג וכולל את הביטוי "מכללת איקום" בצורה טבעית.
2. לוודא שדף הבית מקשר בבירור (לא רק דרך תפריט) לארבעת דפי הקורס בעדיפות: סייבר, AI, שיווק דיגיטלי, Full Stack.
3. להוסיף Organization schema (ראו `templates/schema_template.md`) אם אינו קיים.
4. להכין מקום קבוע בפוטר לעמודי אמון עתידיים (FAQ על המכללה, חוות דעת) – ראו `docs/08_BRAND_SERP_STRATEGY.md`.
5. לבדוק כל טענה גלויה בדף הבית (סטטיסטיקות, שיתופי פעולה, הסמכות) מול טבלת "עובדות מותג" ב-`docs/01_BRAND_GUIDELINES.md` – לסמן כל טענה לא-מאושרת ל-`Needs legal/compliance check`.
